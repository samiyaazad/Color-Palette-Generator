## INTRODUCTION 

I built it with HTML, CSS and JavaScript. I always get confused with color while coding, like which color would look good or what looks good, 
So to solve that problem, I built this project.



## TECHNOLOGIES 

                - VS Code
                - HTML
                - CSS
                - JavaScript



## FEATURES 

           - You can search for any color to use in code.
           - Responsive layout for different screen sizes.
           - By the AI generate button, you can get a random palette every time.



## THE PROCESS 

              - Planned the project idea: a simple tool to generate and copy color palettes.
              - Created the basic HTML structure with a container, button and multiple color boxes.
              - Designed the UI using CSS:
                                          => Used Flexbox to center the layout.
                                          => Used CSS Grid for responsive color boxes.
                                          => Added gradients, shadows, and hover effects for better UI.
              - Integrated Google Fonts (Montserrat) for clean typography.
              - Added Font Awesome icons for copy functionality.
              - Implemented JavaScript logic:
                                          => Created a function to generate random HEX color codes.
                                          => Stored generated colors in an array.
                                          => Dynamically updated UI using DOM manipulation.
              - Added event listener to the Generate button to refresh the palette.
              - Implemented event delegation for handling clicks efficiently.
              - Built a copy-to-clipboard feature using navigator. clipboard.
              - Added visual feedback after copying color.
              - Debugged common issues:
                                          => Fixed typos in class names and selectors.
                                          => Corrected DOM selection methods.
                                         => Ensured consistent HTML structure.
